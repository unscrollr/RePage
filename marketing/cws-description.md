# Chrome Web Store Listing — Updated Copy

## Short description (132 chars max)

Replaces infinite scroll with numbered pages on every website. Blocks autoplay, greyscale mode, mute notifications. Free & open source.

## Full description

Infinite scroll removes stopping points by design. When platforms switched from paginated feeds to infinite scroll, session times went up sharply — NBC saw 30% more mobile pageviews, Quartz 50% more stories per session. The Next Page button wasn't removed because users preferred scrolling. It was removed because removing it is profitable.

RePage puts it back.

Install it and every website gets a numbered nav bar at the bottom of every scrollable area:

‹ 1 2 3 … 47 ›

Works on Reddit, Twitter/X, YouTube, Wikipedia, Gmail, ChatGPT, Gemini, LinkedIn, Facebook, Instagram — any website with a scrollable area.

FEATURES
✓ Numbered pagination on every feed and article
✓ Z / X keyboard shortcuts (right-hand mouse friendly) + arrow keys
✓ Sub-scroll containers (sidebars, TOC panels, chat histories) get their own nav bar
✓ Greyscale mode — renders the page in black & white (less stimulating)
✓ Disable Autoplay — pauses all videos on page load
✓ Mute Notifications — hides unread badges and notification counts
✓ Hide Like Counts — removes engagement metrics
✓ Text-Only mode — strips images and videos from social feeds
✓ Per-site disable — turn RePage off for any domain from the popup

PRIVACY
• Zero data collection
• No account required
• No external requests ever made
• Permissions: activeTab + storage only

Open source: github.com/codycsmith41-a11y/repage
Free forever.
